# Panduan SLA-SKS untuk Guru dan Siswa

Tutorial statis untuk pengguna SLA-SKS MTs Fase D. Buka `index.html` melalui browser atau jalankan `python -m http.server 8000` dari direktori repo.

- `assets/topics.js` berisi topik dan langkah kedua peran.
- `assets/tutorial.js` dan `assets/tutorial.css` mengatur navigasi, pencarian, progres baca, dan tampilan.
- `assets/screenshots/` memuat cuplikan asli yang sudah disiapkan untuk publikasi. Isian akun dan teks soal bank yang terekam disamarkan. Topik yang belum memiliki tangkapan layar dijelaskan melalui langkah tertulis.

## GitHub Pages

Setelah PR ditinjau dan digabung, buka **Settings → Pages**, pilih **Deploy from a branch**, lalu pilih `main` dan `/(root)`. Klik **Save**. Setelah deployment berhasil, buka [Panduan SLA-SKS](https://al-faroz.github.io/sla-sks-tutorial/).
